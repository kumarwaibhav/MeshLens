# Design reference notes

Consulted 2026-11-03. These are primary sources, not endorsements of MeshLens. Platform-specific recommendations were translated to semantic HTML/CSS rather than represented as native iOS implementation.

| Source | Application |
|---|---|
| [Apple design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles) | Useful simplicity, clear purpose, understandable hierarchy |
| [Apple accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) | Readability, contrast and appearance review |
| [Apple layout](https://developer.apple.com/design/human-interface-guidelines/layout) | Task importance, alignment, grouping and adaptability |
| [Apple typography](https://developer.apple.com/design/human-interface-guidelines/typography) | Legible system font stack and scalable text |
| [Apple color](https://developer.apple.com/design/human-interface-guidelines/color) | Semantic colors, text alongside status colors |
| [Apple writing](https://developer.apple.com/design/human-interface-guidelines/writing) | Concrete actions and plain language |
| [Apple onboarding](https://developer.apple.com/design/human-interface-guidelines/onboarding) | Optional contextual guidance and learning by trying |
| [Apple materials](https://developer.apple.com/design/human-interface-guidelines/materials) | Restrained glass on navigation; readable content surfaces |
| [Apple buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) | Explicit action labels, native semantics |
| [WCAG 2.1](https://www.w3.org/TR/WCAG21/) | AA audit target; distinguish AAA target-size guidance |
| [WAI-ARIA tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) | Roving tab focus and keyboard selection |
| [MVTec AD](https://www.mvtec.com/research-teaching/datasets/mvtec-ad) | Official dataset description, download route and noncommercial terms |

The supplied owner feedback is the research input. No interviews, analytics, Figma file, physical-device study or user-feedback service was available. Layout choices and expected impacts are design judgments, not measured research outcomes. See [research synthesis](RESEARCH_SYNTHESIS.md).
