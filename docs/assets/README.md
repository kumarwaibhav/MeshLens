# MeshLens documentation assets

These original architecture figures and actual application captures support the project report and README.

## Diagrams

The eleven diagrams in `diagrams/` are editable SVGs, with PNG renderings for Word/PDF compatibility. `../report/build_assets.py` reads the frozen evaluation for benchmark counts. It does not train a model or alter evaluation records.

The figures cover branding, system context, data roles, active and historical model responsibilities, autoencoder layers, inspection sequence, deployment, benchmark outcomes, stress results, release history and responsive layout. The responsive-layout figure is explicitly a schematic, not a mobile screenshot.

## UI screenshots

The five JPEG files in `screenshots/` were captured from the actual public application at `https://mesh-lens.vercel.app/` on **14 November 2026**, as **1348 by 926 pixel desktop browser captures**. They show the overview, completed bent-defect inspection, dataset explanation, results and method sections. Screenshots were not reconstructed or generated. A fresh mobile screenshot, physical-device test, camera-hardware trial or assistive-technology session was not completed for this documentation update.

The displayed benchmark image and its response are already-evaluated MVTec AD Grid replay data. A screenshot is workflow evidence, not a new accuracy measurement. Inference time and browser-local timestamps in a capture describe that session only.
